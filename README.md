# C++ OOP Projects

## Overview

This repository contains three C++ console-based projects developed to practice and demonstrate fundamental Object-Oriented Programming (OOP) concepts.

Each project simulates a real-world management system using classes, objects, constructors, encapsulation, and vectors for dynamic data storage.

The projects also focus on problem-solving, input validation, and organizing code into reusable functions.

---

## Projects Included

### 1. Library Management System

A console-based application designed to manage library books and borrowing operations.

**Features:**
- View all available books.
- Borrow books from the library.
- Return borrowed books.
- View all borrowed books.
- Add new books dynamically.
- Move books between available and borrowed lists.
- Input validation and error handling.

[View Project](./Library-management-system)

---

### 2. Bank Management System

A console-based application that simulates basic banking operations and account management.

**Features:**
- View all active bank accounts.
- Deposit money into an account.
- Withdraw money from an account.
- Search for accounts using account numbers.
- Update account balances dynamically.
- Validate transactions and handle invalid input.

[View Project](./Bank-management-system)

---

### 3. Student Management System

A console-based application designed to manage student records and their enrolled courses.

**Features:**
- Add new students.
- Delete existing students.
- Add courses to specific students.
- Delete courses from specific students.
- Display all students and their courses.
- Search for students using their IDs.
- Prevent duplicate student IDs.
- Input validation and error handling.

[View Project](./Student-management-system)

3. Compile the C++ source file using a C++ compiler.
